## Interpretation limits

- Train is used for discovery; validation is a single descriptive check on the supplied sample and must not be treated as an independent external replication.
- Rows are sampled frames, not independent participants or repetitions. No confidence intervals or clinical significance are claimed.
- All reported error values describe 2D landmark localization, not exercise correctness, repetition-count accuracy, or treatment outcomes.
- The supplied CSVs contain no test rows. The program rejects any row whose split label differs from its expected input split.
